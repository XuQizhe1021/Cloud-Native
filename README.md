## 老师提供文件说明

1. `ubuntukelong/`
   - VMware 虚拟机文件目录，可直接通过 `.vmx` 导入。

2. `本虚拟机文件说明.pdf`
   - 老师对虚拟机预装环境和后续配置的说明。

3. `jenkins.war`
   - Jenkins 安装包，后续可在 Master 节点通过 `java -jar jenkins.war` 启动。
